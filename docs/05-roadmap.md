# 路线图

> 总计约 3 个月完成 P0–P3 完整自用版本,每阶段都是可演示的。

## Phase 0 · 骨架(2 周) — "能写"

**目标:** 跑得起来,能新建项目,能写章节,文件可被 git 备份

- [ ] Tauri 项目初始化 + 打包脚本
- [ ] 三栏布局 + 主题系统(暗/护眼/亮)
- [ ] 项目创建/打开/删除
- [ ] 树形导航(卷/章)
- [ ] CodeMirror 6 编辑器(md 存储)
- [ ] 文件 IO、字数统计、每日目标
- [ ] 设置面板
- [ ] 沉浸模式
- [ ] 命令面板骨架

## Phase 1 · AI 基础(2–3 周) — "第一个 AI 功能"

**目标:** 选段一按润色,模型可切换,密钥不外泄

- [ ] AI Provider 抽象 + 4 个实现
- [ ] 密钥本地加密存储(系统 keyring)
- [ ] Prompt 模板系统(TOML + 变量)
- [ ] AI 面板(右栏 chat)
- [ ] 选区润色 + diff 接受/拒绝
- [ ] 流式输出、打字机效果
- [ ] Token 用量统计
- [ ] 全局快捷键(润色/续写)

## Phase 2 · 创作闭环(3–4 周) — "全流程 AI 辅助"

**目标:** 从角色/设定/细纲一路 AI 到正文,工作流贯通

- [ ] 细纲编辑(独立面板,带结构化字段)
- [ ] 角色卡系统 + 关系图谱
- [ ] 设定集系统
- [ ] 批注/笔记系统
- [ ] AI 角色设计、设定设计
- [ ] 细纲 → 章节正文生成
- [ ] 续写 + 上下文窗口管理(摘要/滑动窗口)
- [ ] 章节摘要自动生成
- [ ] 选中段落"吐槽/批注"

## Phase 3 · RAG + 文风(3–4 周) — "AI 懂你的书"

**目标:** 写出来像你,问什么 AI 都能在百万字里找到出处

- [ ] LanceDB + Tantivy 集成
- [ ] 嵌入服务(本地 bge-m3 / 云端双栈)
- [ ] 索引构建(场景切分 + 元数据)
- [ ] 混合检索 + Rerank
- [ ] RAG 检索面板 + 引用跳转
- [ ] 文风样本标注 + 特征提取
- [ ] 文风注入到所有生成
- [ ] 一致性检查(角色言行/设定冲突)
- [ ] 风格偏离度反馈
- [ ] 自动更新

## Phase 4 · 打磨(持续)

- [ ] 导出 txt/docx/epub
- [ ] 云同步(可选 WebDAV/坚果云)
- [ ] 性能优化(虚拟列表、懒加载、索引压缩)
- [ ] 插件/自定义提示词市场
- [ ] 番茄钟、统计面板
- [ ] 起点/番茄式批量章节生成
- [ ] iPad 只读客户端(可选)

## 依赖关系

```
P0  ─→  P1  ─→  P2  ─→  P3
 └────────────────────────┘
        (并行优化项)
```
