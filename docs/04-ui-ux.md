# UI/UX 设计

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| **沉浸优先** | 暗色为主、藏起不必要元素、`F11` 沉浸模式 |
| **键盘优先** | 80% 常用操作有快捷键,全局命令面板 `Ctrl+Shift+P` |
| **信息密度可调** | 紧凑/标准/宽松 三档,正文字号 14–22px |
| **零等待感** | 一切流式:AI 输出、文件保存、索引重建 |
| **优雅动效** | 200ms 内过渡,严禁阻塞动画,使用 transform/opacity |
| **中文优化** | 思源宋体/方正悠宋/霞鹜文楷 可选,行高 1.7 起 |

## 3. 关键屏幕

### 沉浸写作模式(`Ctrl+Shift+B`)
- 隐藏所有面板
- 当前段落居中,最大宽度 720px
- 底部一行状态:字数/时长
- 任意键唤起菜单

### AI 命令面板(`Ctrl+Shift+P`, 类似 VSCode/Sublime)
```
> 润色:中度
  润色:轻度
  润色:重度
  改写:更紧凑
  续写
  ────────
  生成本章正文(基于细纲)
  生成下一节拍
  生成角色:师父
  ────────
  搜索全书中"林远"的所有出场
  问 RAG:...
```

### 选区浮动 AI 工具条(选中文本后)
- 选中文本上方浮出:`✨润色  📝改写  ➕续写  🔄扩写  💬吐槽  📋复制`
- 接受/拒绝 diff(类似 GitHub PR 风格)
- 历史记录可回滚

### 角色卡
- 左:列表(头像/名字/角色弧光曲线)
- 右:详情 tab(基础/性格/背景/关系/出场)
- 关系图谱:力导向图,可拖拽
- `✨ AI 辅助设计`按钮

### RAG 检索面板
- 类聊天界面 + 引用卡片
- 引用块可点击跳转原文位置
- 筛选器:章节/角色/时间

## 4. 视觉风格

- **暗色基调**:`#0F1115` / `#1A1D24` / `#252A35` / 文字 `#D4D7DD`
- **强调色**:用户可自选(默认:琥珀 `#E5A55C`)
- **字体**:中文 `霞鹜文楷`(免费、可商用) / `思源宋体`,等宽 `JetBrains Mono`
- **微质感**:1px 边框、4px 圆角、微妙阴影、玻璃拟态顶栏
- **品牌色**:深墨绿 + 暗金点缀,体现"文房四宝"质感(保持现代)

## 5. 快捷键体系(规划)

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+K` | AI 助手(右栏唤起) |
| `Ctrl+Enter` | AI 续写 |
| `Ctrl+Shift+F` | 全书 RAG 检索 |
| `Ctrl+Shift+B` | 沉浸模式 |
| `Ctrl+1/2/3` | 切换右栏(角色/设定/AI) |
| `Ctrl+Shift+V` | 选区润色 |
| `Ctrl+Shift+R` | 选区改写 |
| `Ctrl+Shift+E` | 选区扩写 |
| `F2` | 重命名(卷/章/角色) |
| `Ctrl+D` | 复制当前章节 |

## 6. 主题

- 内置 3 套: 暗色(默认)、护眼(米黄)、亮色
- 自定义主题编辑器
- 字体/字号/行高可调
- 跟随系统
