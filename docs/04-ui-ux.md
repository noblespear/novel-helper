# UI/UX 设计

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| **作家助手对齐** | 信息架构让网文作者零学习曲线,剥离 AI 后核心流与 作家助手 一致 |
| **沉浸优先** | 暗色为主、藏起不必要元素、`Ctrl+Shift+B` 沉浸模式 |
| **键盘优先** | 80% 常用操作有快捷键,全局命令面板 `Ctrl+Shift+P` |
| **零等待感** | 一切流式:AI 输出、文件保存、索引重建 |
| **优雅动效** | 200ms 内过渡,严禁阻塞动画,使用 transform/opacity |
| **中文优化** | 多字体可选(霞鹜文楷/思源宋体/系统),行高 1.7 起 |

## 2. 与 阅文作家助手 的关系

| 维度 | 作家助手 | NovelHelper |
|---|---|---|
| **信息架构** | 顶部面包屑 + 左章节树 + 右大纲/人物 | **对齐** — 网文作者打开"秒懂" |
| **视觉表现** | 扁平、平面、小间距 | **升级** — 5 级文字层级、8px 圆角、1px 边框、骨架屏 |
| **暗色模式** | 深灰底 + 起点红强调 | **升级** — 深墨绿底 + 琥珀金强调(典雅不模仿平台) |
| **AI 功能** | 浅尝辄止,入口深 | **差异** — 浮动工具条 + 全局命令面板 + RAG + 文风学习 |
| **编辑器** | 普通富文本 | **差异** — CodeMirror 6 虚拟化,百万字不卡 |
| **护眼主题** | 米黄 | **对齐** — 米色底 + 暖棕文字 |
| **卡顿** | 长篇卡顿 | **差异** — 虚拟滚动 + 懒加载 + 索引分离 |

## 3. 信息架构

```
NovelHelper
├── 作品管理 (顶层)
│   ├── 我的作品列表
│   └── 新建/导入作品
│
├── 写作 (进入作品后主界面)
│   ├── 章节目录 (左栏,树形:卷/章)
│   ├── 编辑器 (中栏)
│   ├── 右侧栏 (可切换:大纲/人物/AI助手/RAG)
│   └── 状态栏 (底部:字数/目标/番茄钟/AI状态)
│
├── 大纲
│   ├── 总体大纲
│   ├── 细纲 (按章节)
│   ├── 人物关系图
│   └── 时间线
│
├── 人物
│   ├── 列表 (主角/配角/反派)
│   ├── 角色卡 (性格/背景/动机/关系)
│   └── 关系图谱 (力导向图)
│
├── 设定
│   ├── 世界观
│   ├── 力量体系
│   ├── 势力门派
│   ├── 地理
│   └── 物品/法宝
│
├── 素材
│   ├── 素材库
│   ├── 灵感碎片
│   └── 引用摘抄
│
├── 工具
│   ├── AI 助手 (我们的核心差异)
│   ├── 取名
│   ├── 排版
│   └── 敏感词检测 (后期)
│
└── 设置
    ├── 主题/外观
    ├── 快捷键
    └── AI 配置
```

**与作家助手的差异:** 去掉"数据/稿费/签约/消息"等平台绑定模块;AI 助手从"工具"提升为一等公民。

## 5. 关键交互

### 5.1 沉浸写作模式(`Ctrl+Shift+B`)
- 隐藏左栏 + 右栏 + 底栏,只保留编辑器
- 当前段落居中,最大宽度 720px
- 底部一行状态:字数/时长
- 任意键唤起菜单

### 5.2 选区浮动 AI 工具条(选中文本后)
```
   选区
   ┌──────────────┐
   │ 选中文字...  │
   └──────────────┘
      ┌──────────────────────────────┐
      │ ✨润色  📝改写  ➕续写  🔄扩写 │
      │ 💬吐槽  📋复制  📖查 RAG      │
      └──────────────────────────────┘
```
- 接受/拒绝 diff(类似 GitHub PR 风格)
- 历史记录可回滚

### 5.3 AI 命令面板(`Ctrl+Shift+P`, 类似 VSCode)
```
> 润色:中度
  润色:轻度
  润色:重度
  改写:更紧凑
  续写
  ────────
  生成本章正文(基于细纲)
  生成下一节拍
  生成角色:师父
  ────────
  搜索全书中"林远"的所有出场
  问 RAG:...
```

## 6. 主题与视觉风格

### 6.1 三套主题

| 主题 | 背景 | 文字 | 强调色 | 用途 |
|---|---|---|---|---|
| **暗色**(默认) | `#0F1612`(深墨绿) | `#D4CFC2`(米白) | `#E5A55C`(琥珀) | 夜间/长久写作 |
| **护眼** | `#F4ECD8`(米黄) | `#3C3327`(暖棕) | `#C27841`(暖橘) | 白天/护眼 |
| **亮色** | `#FAFAF7`(暖白) | `#1A1714`(暖黑) | `#D4904F`(金) | 偏好亮色 |

### 6.2 字体

- **中文默认**:系统无衬线体(Segoe UI / 微软雅黑)
- **可选**:霞鹜文楷(免费、可商用、书法感)、思源宋体、方正书宋
- **等宽**:JetBrains Mono (代码 / 数值)
- **行高**:14–22px,可调节

### 6.3 视觉细节

| 元素 | 值 |
|---|---|
| 按钮 | 1px 边框、8px 圆角、微阴影 |
| 卡片 | 背景差 `#ffffff` on `#FAFAF7`、8px 圆角、1px 边框 |
| 文字层级 | 5 级(标题/副标题/正文/辅助/标签) |
| 动效 | 200ms ease, transform + opacity 不阻塞 |
| 加载 | 骨架屏 + 局部 spinner,无整页 loading |
| 错误 | 行内提示 + Toast,不弹窗 |
| 间距 | 宽松(16px 基准) |
| 暗色高亮 | 琥珀 `#E5A55C`(不等于任何平台的红/橙) |

### 6.4 自定义主题(后期)

- 用户可编辑:背景色、文字色、强调色、字体、行高
- 导入/导出主题文件

## 7. 快捷键体系

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+K` | AI 助手(右栏唤起) |
| `Ctrl+Enter` | AI 续写 |
| `Ctrl+Shift+F` | 全书 RAG 检索 |
| `Ctrl+Shift+B` | 沉浸模式 |
| `Ctrl+1/2/3` | 切换右栏(大纲/人物/AI) |
| `Ctrl+Shift+V` | 选区润色 |
| `Ctrl+Shift+R` | 选区改写 |
| `Ctrl+Shift+E` | 选区扩写 |
| `Ctrl+S` | 保存 |
| `F2` | 重命名(卷/章/角色) |
| `Ctrl+D` | 复制当前章节 |
| `Ctrl+Shift+N` | 新建章节 |
| `Ctrl+.` | 收起/展开左栏 |
| `Ctrl+,` | 收起/展开右栏 |
| `Alt+↑/↓` | 章节排序(树内移动) |
